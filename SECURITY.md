# Security and private data

Never post ROMs, credentials, access tokens or downloaded music. Logs and seed
reports can contain local filesystem paths; review them before sharing.

For a suspected vulnerability involving account data, server authentication,
arbitrary files or code execution, use the repository's **Security → Report a
vulnerability** if private reporting is available. Otherwise contact the repository
owner privately through an existing trusted channel before posting exploit details.
No dedicated public security address is currently advertised.

ALPHA-0.24 is an experimental development snapshot, with no security-support SLA.
The game does not yet authenticate players with Discord or automatically submit
runs to a public leaderboard. Receiver credentials belong on the server and must
never be shipped in a game client.
