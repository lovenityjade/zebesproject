# Changelog

## ALPHA-0.26 — 2026-09-19

- Playable ten-encounter Boss Rush, five difficulties, progressive equipment,
  native menus, boss-energy display, results and optimized VR transitions.
- Pixel-textured Mother Brain finale and Hyper Beam, escape lighting/fireballs
  and seven animated portrait exchanges with corrected native punctuation.
- Forty additional achievements, with separate Vanilla/Randomizer categories.
- External pixel/tile studio, parallax editing and accepted room corrections;
  imported decoration pixels are reconstructed from the player ROM at runtime.
- Rendering quality, transition detail, frame caps and resolution controls.
- Normalized, credited Boss Rush/finale audio in both desktop packages.
- Document future optional QoL separately; these options are not implemented
  in this release and will not qualify for speedrun mode.

## ALPHA-0.25 — 2026-09-18

- French Canadian language choice across game and randomizer menus, native text,
  messages, cinematics, credits, trackers and the website/help. English remains available.
- Requested Special Thanks for Guiz de Pessemier and Eric Certossini.
- Seed-dependent map layout and saved-station travel; save refills default on
  for fresh configurations, while existing preferences are retained.
- Suit transformation presentation, Maridia border cleanup and Mother Brain
  widescreen sprite clipping corrections.
- Native story-dialogue foundation and restored planetary escape presentation.
- Windows retains the native-library hotfix and the selected Remastered tracks.


## ALPHA-0.24 — 2026-09-16

- Native mode selector: Vanilla, Story preview, Boss Rush preview and Randomizer.
- Contextual menu rows, fixed Start Game position and per-slot mode emblems.
- Story and Boss Rush cannot start; Boss Rush previews four difficulty levels.
- Sharp startup notices on black, native tall year digits and cinematic fades.
- Visible build version in the front end. `VERSION` is the authoritative label.
- Freeze the accepted Linux development build and record its validation and hashes.
- Add the project README, contributor credits, bug-report template and release checklist.
- License project-authored code under MIT, with separate terms for original artwork.
- Target Windows and Linux packages; macOS is outside this release's scope.
- Keep distribution blocked pending asset provenance review and platform validation.
